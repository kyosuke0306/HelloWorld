Tutorial

        
      

      

        

          
🎯 クリア条件

          
選んだ言語のプログラムを実行して、ターミナルに Hello World と表示されたらクリアです。

        

        

          
🧭 流れ

          
    
            
  1. ターミナルでプログラム用のファイルを作る
    2. 
            
  2. エディタでそのファイルにプログラムを書く
    3. 
            
  3. ターミナルでプログラムを実行する（言語によっては先にコンパイルが必要）
    4. 
          

          
エラーが出たらメッセージをよく読んで直してみよう。本物そっくりのエラーが出ます。

        

        

          
💻 ターミナル

          
    
            
  • コマンドを入力して Enter で実行
    • 
            
  • help で使えるコマンドの一覧を表示
    • 
            
  • ↑ ↓ で前に入力したコマンドを呼び出し、Tab でファイル名を補完
    • 
            
  • ls でファイル一覧、clear で画面をきれいにする
    • 
          

        

        

          
📝 エディタ

          
    
            
  • ファイルを作ると自動でタブが開きます
    • 
            
  • 書いた内容は自動で保存されます
    • 
            
  • 括弧やクォートは自動で閉じ、改行すると自動でインデントされます
    • 
          

        

        

          
📱 スマホのキーボード

          
    
            
  • Editor / Terminal で入力先を切り替え（画面をタップしても切り替わります）
    • 
            
  • ← ↑ ↓ → でカーソル移動、Tab でインデント
    • 
            
  • 123 で数字と記号、#+= でその他の記号、ABC で英字に戻る
    • 
            
  • ⇧ で大文字（2回押すと固定）、↶ ↷ で元に戻す／やり直し
    • 
          

        

        

          
⏱ タイムアタック

          
言語を選んだ瞬間から計測スタート。クリアするとタイムが表示され、各言語のベスト記録がスタート画面に残ります。
