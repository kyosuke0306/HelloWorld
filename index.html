Tutorial

        
      

      

        

          
01クリア条件GOAL

          
選んだ言語のプログラムを実行して、ターミナルに Hello World と表示されたらクリアです。

          
        


        

          
02画面の見方SCREEN

          
          

            
A
エディタ: プログラムを書く場所。作ったファイルがタブで開く

            
B
ターミナル: コマンドを打ってファイルを作ったり、プログラムを実行する場所

            
C
キーボード: スマホのときだけ表示

          

        


        

          
03流れFLOW

          
          
言語によっては、実行の前にコンパイル（プログラムを実行できる形に変換すること）が必要です。エラーが出たらメッセージをよく読んで直してみよう。本物そっくりのエラーが出ます。

        


        

          
04ファイル名FILE NAME

          
ファイルは touch ファイル名 で作れます。ファイル名は「名前」と「拡張子」でできています。

          
          

            
言語拡張子例

            
              
Python.pyhello.py

              
Java.javaHello.java

              
C言語.chello.c

            
          

          
    
            
  • 半角の英数字で付ける（全角・スペースは使わない）
    • 
            
  • 大文字と小文字は別物として扱われる（Hello.java と hello.java は別のファイル）
    • 
            
  • 名前の部分は自由。ただし Java は、ファイル名とプログラム中のクラス名を同じにする決まりがある
    • 
          

        


        

          
05ターミナルTERMINAL

          
    
            
  • コマンドを入力して Enter で実行
    • 
            
  • help で使えるコマンドの一覧を表示
    • 
            
  • ↑ ↓ で前に入力したコマンドを呼び出し、Tab でファイル名を補完
    • 
            
  • ls でファイル一覧、clear で画面をきれいにする
    • 
          

        


        

          
06エディタEDITOR

          
    
            
  • ファイルを作ると自動でタブが開きます
    • 
            
  • 書いた内容は自動で保存されます
    • 
            
  • 括弧やクォートは自動で閉じ、改行すると自動でインデントされます
    • 
          

        


        

          
07スマホのキーボードKEYBOARD

          
          
    
            
  • Editor / Terminal で入力先を切り替え。選んでいる方が青い枠で大きく表示される（画面をタップしても切り替わる）
    • 
            
  • ← ↑ ↓ → でカーソル移動、Tab でインデント
    • 
            
  • 123 で数字と記号、#+= でその他の記号、ABC で英字に戻る
    • 
            
  • ⇧ で大文字（2回押すと固定）、↶ ↷ で元に戻す／やり直し
    • 
          

        


        

          
08タイムアタックTIME ATTACK

          
          
言語を選んだ瞬間から計測スタート（エディタ右上に表示）。クリアするとタイムが表示され、各言語のベスト記録がスタート画面に残ります。
